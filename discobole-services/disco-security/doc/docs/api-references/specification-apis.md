# APIs Specifications

???+ info "OpenAPI Specifications"
    The Permission Management Component exposes the TMF672 User Role Permission Management API.

    This API is responsible for the user role creation. A user role is defined as the entity that defines a set of privileges covering various functions and/or manageable assets. When a user is assigned a given role then it is actually allocated all the privileges defined for that role type and the corresponding permissions are created for that user.
