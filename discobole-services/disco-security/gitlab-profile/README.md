# User Roles Permissions Component

Responsible for user roles and permissions based on TMF672 API. It includes the model definition as well as all available operations for creating user permissions to access manageable assets.

## Getting Started

### Prerequisites

- [git](https://git-scm.com/)
- [Java](https://jdk.java.net/) 17
- [Maven](https://maven.apache.org/) 3.8

### Installing

To install locally recursively the projects, please clone the [know-how project](https://gitlab.ow2.org/discobole/disco-project/know-how).

```bash
git clone git@gitlab.ow2.org:discobole/disco-project/know-how.git
cd know-how
```

By default, the projects are cloned into `$HOME/workspaces`. To change the workspaces folder and other options, please run `git-all --help` script.

Then clone all repositories of `disco-security`, as follows:

```bash
git-all clone discobole/disco-oda-components/disco-security
```
