# Introduction

DISCOBOLE Suite proposes frontends/user interfaces (UIs) for the **Administration and Management of the DISCOBOLE Components**.

**Admin Portal UI** is a user interface that can be used in the context of Product Inventory (CPIB) Component to monitor the delivery of customer products and product prices. It also enables to export products, define some batch process to purge the database and has some reporting features. All these usages are described in the below pages.

The administrator gets authenticated through Keycloak and the DISCOBOLE User Role & Permission Component. Depending on their permissions, they can access the admin console for the 3 components (OM for Order Management, CPIB for Product Inventory, COOD for Customer Order Orchestration Delivery) or only some of them.
