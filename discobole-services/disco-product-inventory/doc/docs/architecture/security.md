# Security In Product Inventory

## Authentication

Bearer token in http request are used to authenticate the user.

## Authorization

Currently the following roles are supported:

- `CreateProduct`
- `ReadProduct`
- `UpdateProduct`
- `DeleteProduct`
- `ExportProduct`
