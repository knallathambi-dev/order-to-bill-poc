# TMF Conformance Report

The TMF API conformance profile of the REST API is specified to set a minimum standard or baseline of the API implementation that is expected. Thus, the conformance profile provides a highlevel definition of API conformance and describes how conformance testing can be carried out.

The API Conformance Test Kit (CTK) is a TMF tool checking that API implementation respects requirement of the API conformance profile.

Please refer to [TMF637 Product Inventory Management API v5.0.0](https://www.tmforum.org/oda/open-apis/directory/product-inventory-management-api-TMF637/v5.0.0) to consult the API Conformance profile.

???+ summary "Today (in April 2025), _Product Inventory Management_ API is [65%](conformance/product-inventory.html) conformant with TMF637 guidelines."
