# product-inventory-custom-annotator


## Description

This library represents a custom annotator to be used by the maven plugin `jsonschema2pojo`.

The goal of this project is to add `lombok` annotations to the JAVA classes generated by the `jsonschema2pojo` plugin.

## How to use it?

When setting up the `jsonschema2pojo` Maven plugin within your project, it should be configured in the following manner:

```xml   

<plugin>
    <groupId>org.jsonschema2pojo</groupId>
    <artifactId>jsonschema2pojo-maven-plugin</artifactId>
    <version>1.2.0</version>
    <dependencies>
        <dependency>
            <groupId>org.disco.utils</groupId>
            <artifactId>custom-config</artifactId>
            <version>1.0-SNAPSHOT</version>
        </dependency>
    </dependencies>
    <executions>
        <execution>
            <goals>
                <goal>generate</goal>
            </goals>
            <configuration>
                <sourceDirectory>${project.basedir}/src/main/resources/schema</sourceDirectory>
                <targetPackage>com.orange.discobole.productinventory.generated</targetPackage>
                <customAnnotator>
                    com.orange.discobole.productinventory.customAnnotator.LombokAnnotator
                </customAnnotator>
            </configuration>
        </execution>
    </executions>
</plugin>
```

The important part is the following config that refers to the `Annotator` class:

```xml

<customAnnotator>com.orange.discobole.productinventory.customAnnotator.LombokAnnotator
</customAnnotator>
```
