# Order Management - An ODA compliant component responsible for order processing and follow up

## What & Why

!!! abstract "What is DISCOBOLE Order Management?"
    Order management component (OM) is detonated to telco service provider intending to offer an ODA/TMF compliant component handling the order capture and order follow-up processes and managing the related productOrder data.  
    It represents the TMF Product Order Capture & Validation component (TMFC002) within the ODA Core Commerce Management domain.

    OM provides:  
    
     - Centralized order capture process allowing a Cross-Channel user experience.  
     - Catalog driven order capture process.  
     - Seamless integration with TMF interfaces via standard APIs.  
     - Event-driven order processing for quick and dynamic handling.

## History & Perspectives

!!! info "History and Perspectives"
    - The architecture is microservices-based, cloud-native, and hosted on a private cloud.
    - The development of the [DISCOBOLE-Order-Management](https://gitlab.ow2.org/discobole/disco-oda-components/disco-order-management) component was initiated in the context of the [DISCOBOLE](https://discobole.ow2.io/doc/) project that the aim is to develop an agile & disruptive IT Product (suite of OpenSource components) on the scope Order To Bill & Customer Order Orchestration and Delivery (COOD)
    - This suite of OpenSource components are based on TM Forum ODA component definition, implements the TM Forum APIs and is based on TM Forum SID data model while complying with Orange’s functional architecture principles.
