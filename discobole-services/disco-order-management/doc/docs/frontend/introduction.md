# Introduction

DISCOBOLE Suite proposes frontends/user interfaces (UIs) for the **Administration and Management of the DISCOBOLE Components**.

**Admin Portal UI** is a user interface that can be used in the context of Order Management (OM) Component to monitor the delivery of customer orders and set on or off some application settings regarding the OM order capture process based on the integration context.

The administrator gets authenticated through Keycloak and the DISCOBOLE user role & permission component. Depending on their permissions, they can access the admin console for the 3 components (OM, CPIB, COOD) or only some of them.
