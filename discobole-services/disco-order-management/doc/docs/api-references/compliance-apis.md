# TMF Compliance Reports

As per architecture committee decision [0034 - Contract First Approach for API REST Implementation](https://discobole.ow2.org/doc/architecture/decisions/0034-contract-first-approach/), during the design stage, the API REST specifications of the Order Management Component should follow the [TMF630 guidelines v4.0.1](https://projects.tmforum.org/wiki/display/PUB/TMF630+REST+API+Design+Guidelines+v4.0.1).

???+ summary "Today (3 Sept 2024), Product Ordering Management API is compliant at [96%](compliance/order-inventory.pdf) to the TMF630 guidelines."
