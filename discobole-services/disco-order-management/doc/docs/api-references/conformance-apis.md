# TMF Conformance Report

The Conformance Test Kit (CTK) is a set of automated tests that can be run against specific APIs to determine conformance with TMF specifications. It is an npm project that uses the end-to-end testing framework Cypress to invoke a configurable URL where the TMF API is deployed. To run the tests, Node.js must be installed, along with a running instance of the application to be tested.
Please refer to [TMF: Product Ordering Management API](https://www.tmforum.org/oda/open-apis/directory/product-ordering-management-api-TMF622/v5.0) to download the CTK.

!!! info "Today (in February 2025), Product Ordering Management API is conformed at [73%](conformance/order-inventory.html) to the TMF622 Conformance profile."
