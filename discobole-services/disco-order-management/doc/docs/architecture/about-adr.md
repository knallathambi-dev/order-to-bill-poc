# About Architecture Decisions Records

!!! summary "Architecture Decisions Records"
    ADR is a lightweight way to keep track of the important architecture decisions that are made through the life of the project that led to the actual architecture. Each ADR is a small templated markdown file kept along the source code.

    More on information the [why](https://martinfowler.com/articles/scaling-architecture-conversationally.html#adr) and [how](https://adr.github.io).

!!! info "Generated from the Source Code"
    As for now, ADRs concerning `DISCOBOLE Order Management Component` are managed by the Technical Architecture Committee of [DISCOBOLE](https://discobole.ow2.io/doc/); these ADRs are visible directly here.

!!! info "Common ADRs for [DISCOBOLE](https://discobole.ow2.io/doc/)"
    All common ADRs to [DISCOBOLE](https://discobole.ow2.io/doc/) which are applicable to DISCOBOLE Order Management Component as well by inheritance can be found at [DISCOBOLE Architecture Decisions section](https://discobole.ow2.io/doc/architecture/overall-architecture/).
