# TMF Conformance Reports

The TMF API conformance profile of the REST API is specified to set a minimum standard or baseline of the API implementation that is expected. Thus, the conformance profile provides a highlevel definition of API conformance and describes how conformance
testing can be carried out.

As of now, the Order Orchestration & Delivery component APIs are not concerned by the API Conformance profile because those APIs are not yet TMF APIs.
