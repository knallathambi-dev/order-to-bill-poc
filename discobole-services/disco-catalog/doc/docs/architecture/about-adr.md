# About Architecture Decisions Records

!!! summary "Architecture Decisions Records"
    ADR is a lightweight way to keep track of the important architecture decisions that are made through the life of the project that led to the actual architecture. Each ADR is a small templated markdown file kept along the source code.

    More on information the [why](https://martinfowler.com/articles/scaling-architecture-conversationally.html#adr) and [how](https://adr.github.io).

!!! info "ADR management process"
    As for now, ADRs concerning the `DISCOBOLE Product Catalog` project are managed by the Technical Architecture Committee of the `DISCOBOLE` project.

!!! info "Common ADRs for DISCOBOLE project"
    All common ADRs to DISCOBOLE project which are applicable to ODACAT as well by inheritance can be found at this link in the Architecture Decisions section. [Overall architecture](https://discbole.ow2.io/doc/architecture/overall-architecture/)
