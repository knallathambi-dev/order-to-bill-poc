# Orange and TMF compliance reports

As per architecture commitee decision [0034 - Contract First Approach for API REST Implementation](https://disco.pages.gitlab.tech.orange/disco-website/architecture/decisions/0034-contract-first-approach/), the Product Catalog component  APIs are specified then released by [API Designer](https://designer.api.intraorange/ui/#/ad/home). During the  design stage, the specifications should follow the Orange recommendations and TMF recommendations.

The compliancy to the Orange and TMF guidelines is checked thanks to the Orange compliance tool __[Orange compliance tool](https://tools.api.intraorange/compliance)__  which is integrated into [API Designer](https://designer.api.intraorange/ui/#/ad/home).

???+ summary "Today (in April 2025), _Product Catalog Management_ API is compliant at [90%](compliance/catalog-product-catalog.pdf) to the TMF630 guidelines."

???+ summary "Today (in April 2025), _Policy Rule_ API is compliant at [93%](compliance/catalog-policy-rule.pdf) to the TMF630 guidelines."
