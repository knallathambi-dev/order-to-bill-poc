# Introduction

The Product Catalog UI serves as the central interface for defining and managing all catalog entities. The below pages provides guidance on the [Bottom Up Approach](../entities/bottom-up-approach/) used for configuring the Product Catalog. It details how to create, manage and visualize all Product Catalog entities including Product Offering, Product Specification, Product Offering Price, Policy Rule, and reference data such as Currencies, Units, etc., in the [Catalog Administration](../administration/).

???+ info "Preferred Browser"
    __Internet Explorer__ is the recommended browser for DISCOBOLE Product Catalog UI. Alternative browser, for instance Mozilla Firefox, might bring restriction when defining Validity dates & Times of entities.

## Login page

Access to the ODACAT Product Catalog begins with the login page. Please authenticate to proceed to the main interface.

![ODACAT Login](../../img/ui-odacat-login.png)

## Homepage

Upon successful login, you will be directed to the ODACAT Product Catalog homepage

![ODACAT Homepage](../../img/ui-odacat-homepage.png)

This interface comprises two primary panels:

- **Left Panel**:  
    - **Catalog Entity** section: Displays a list of managed entities with direct links to their respective dashboards.  
    - **Administration** section: Provides access to catalog settings and administrative functions. For detailed procedures, refer to the [Catalog Administration](../administration/). It is collapsed by default.  
- **Main panel**:      
    - **Entity Type Display**: Located at the top left, this indicates the currently selected entity type (e.g., 'Product Offering', 'Product Specification'). Selecting a different entity type updates the dashboard accordingly. By default, the 'Product Offering' dashboard is displayed upon login.  
    - **Action buttons**: Positioned at the top right, these allow you to **Refresh** the current view, **Export** the list of entity instances and **Create** a new entity instance  
    - **Search and Filter Area**: Enables users to specify criteria for searching and filtering entity instances.  
    - **Entity Instances Table**: Displays a list of instances for the selected entity type, highlighting key characteristics and available actions for each instance.
