# Roadmap

## Implementation

??? success "Release 10 - March 2026"
    - Handling instalment plans for offerings.
    - Creation of recurring discounts applicable for specific time periods.
    - Rounding off price values according to currencies.
    - Implementation of relationships for migration of contracts.
    - UI & BE refactoring for category processes.
    - UI new screens for mass exports & updates to policy rule screens.
    - Minor security vulnerability fixes. 

??? success "Release 9 - November 2025"
    - Implementation of Tax management.
    - Commitment period implementation.
    - New UI enhancements for product specification, product offering prices, graphical views.
    - Performance improvements and bug fixes.
    - Security vulnerabilities fixes.
    - Eco design best practices implementation.

??? success "Release 8 - June 2025"
    - Introduction of fiber offer in the catalog.
    - Implement selection for either/or scenarios for product offerings ex. device selections.
    - New UI with improved themes, accessibility and standardization released for product offering process.

??? success "Release 7 - February 2025"
    - Enhance catalog to support rating and billing information like rollovers, cycle based charging and proration for mobile postpaid.
    - Catalog UI- Implementation of catalog administration screens for users, user roles and permissions.
    - Catalog UI- Enable management for policy rules through UI.

??? success "Release 6 - October 2024"
    - Introduction of discounts.
    - Catalog export functionality.
    - Implement offer validity management.

??? success "Release 5 - June 2024"
    - Catalog UI- Implementation of catalog administration screens for users, user roles and permissions.
    - Catalog UI- Enable management for policy rules through UI.

??? success "Release 4 - March 2024"
    - Implementation of policy rule API TMF723 to manage policy rules.
    - Implementation of authorisation based on user roles.
    - Catalog UI- Enable creation and modification of all product catalog managed entities: product offering, product offering price, 
      product specification & category.
    - Implement policy rules to manage tariffs based on product characteristics/external attributes.

??? success "Release 3 - December 2023"
    - Catalog 701 Process revamp for product offerings, product specifications, product offering price and
      category.
    - Catalog UI implementation for product specification and lifecycle management process.
    - Implementation of observability software like Jaeger and Prometheus.
    - Integration of Grafana.

??? success "Release 2 - September 2023"
    - Product Offering creation.
    - Catalog UI implementation for product offering create process.
    - Implementation of Keycloak for IAM authentication.
    - Integration of SonarCube.

??? success "Release 1  - July 2023"
    - Implementation of TMF701 Process Flow API - GET/PUT/POST/PATCH for the product catalog entities: product offering, product specification, category and product offering price.
    - Implementation of TMF620 to enable GET operations for consuming systems.
    - Implementation of mock service and resource catalog events.

## Work in progress

    - Grant discount in the context of customer installed base.
